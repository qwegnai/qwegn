# Disqualified Patterns & YAGNI Guardrails (`ADR-012`, `ADR-019`, `ADR-022`)

Consult this registry before proposing new Qwegn UI surfaces, CLI tools, targets, or knobs. These patterns were formally audited and disqualified because they duplicate external harnesses, violate OS/hardware realities, or add one-time demo chrome.

| ID | Disqualified Pattern | Why It Fails YAGNI / Codebase Physics | What To Do Instead |
| :--- | :--- | :--- | :--- |
| **`DISQ-01`** | `/ui` Guard Simulators, Cognitive Sliders, `qwg cognitive` 8-verb CLI | External harnesses invoke `qwg mcp` automatically; `Live Logs` already traces callers/routes; sliders undermine calibrated `0.70` code rails. | Keep `QWCognitiveRails` + MCP headless; default `qwg_vault_query` `screen=true`. |
| **`DISQ-02`** | 3-Pane Split-Pane Flight Deck (`Chat + Decisions + Live Trace`) | Crams chat into `360px` beside redundant raw telemetry; `Chat` already shows `X-Qwegn-Decision-Route`. | Keep the 6 clean `/ui` tabs (`Monitor`, `Decisions`, `Chat`, `Models`, `Live Logs`, `Settings`). |
| **`DISQ-03`** | Zero-Python Metal 4 Quantizer (`qwg quantize` v2) & `/ui` Pack Studio | Violates `QwgSubcommands.swift:60`; users `qwg pull` pre-packed `.qwp` repos, never `400 GB` BF16 shards; creates dual-packer parity tax. | Keep `Scripts/quantize/pack.py` + `ADR-009` offline calibration gates in Python. |
| **`DISQ-04`** | Sparse LSA Citations, Token Entropy Ribbons, Draft Tree, `16×5` MoE Heatmap, Loopback OTLP | Unavailable on dense attention; ignored by coding agents (`read_file`/`qwg_vault_query`); attention mass != factual truth. | Keep `Monitor` spec acceptance metrics and `QWRequestTraceContext` stack logs. |
| **`DISQ-05`** | Seatbelt-Sandboxed Native `qwg agent`, `/ui?tab=agent`, `B=3` Patch Race | `Claude Code`, `OpenCode`, `Codex`, and `Hermes` already run offline against `:8080`; `Law 13` serializes `make test` across branches anyway. | Empower external harnesses over `/v1/*` and compact `/mcp` (`ADR-012`). |
| **`DISQ-06`** | Hot-Swap GEMM LoRA, `/v1/batches`, Overnight Sleep Consolidation | Forward-only engine lacks autograd/backprop; GEMM LoRA epilogues bloat hot PSOs; `.qwcache` solves repo recall without weight mutation. | Keep inference kernels LoRA-free and invest in `.qwcache` Vault v2. |
| **`DISQ-07`** | `4×4` Cosine Matrix Workbench, `#modal-mount-sidecar`, global `embeddingDefaultDimensions` knob | Embeddings are consumed programmatically by SDKs/RAG; `dimensions` belongs per-request in JSON, not global macOS Settings. | Dispatch native `.sequencePair` cross-encoder batches in `/v1/rerank`. |
| **`DISQ-08`** | `/ui` SVG Session Branch DAG, `qwg repl /fork`, `.qwsess` custom format, `Qwegn.app` Tree card | Agents fork/resume automatically via `previous_response_id` and `/v1/sessions/*`; LRU/spill belongs under `warmCacheLimitGiB`/`ssdCacheLimitGiB`. | Upgrade `QWKVCache.adoptSharedPrefixCOW` + `DriverSessionTree` headlessly. |
| **`DISQ-09`** | Heuristic pixel-luminance WCAG / `IoMinA` UI Defect Engine & `/ui` Visual Grounding Stage | Fuzzy neural boxes + 10th/90th-percentile luminance misfire on icons/gradients; web/macOS already have DOM & `AXUIElement` checks. | Ship isolated `SCWindow` / Simulator capture (`--window` / `qwg_capture_window`) only. |
| **`DISQ-10`** | Duplex `WS /v1/realtime` Voice Orb, 24-bar EQ, global `⌥Space` desktop HUD | Coding engineers do not hold duplex voice chats with a local server; `⌥Space` collides with Spotlight/Raycast. | Only build headless `L4.0 QWAudio` ASR (`--load-audio` default `false`) when onboarding an Omni pack. |
| **`DISQ-11` / `DISQ-13`** | Unprivileged fake `ANE %`/`AMX %` gauges, `#if canImport(CoreAI)`, un-spiked `QWANE` | macOS blocks unprivileged `ANE %`/`AMX %`; `v0.42` NAX already retains `91.3%` decode; CoreML transposes can erase theoretical gains. | Gate `QWANE` strictly on a `Scripts/spike/` A/B (`>= +10%` `tok/s` + `100%` SHA-256 parity, `<= 2` tries). |
| **`DISQ-12`** | `QwegnKit.xcframework` Mach/XPC Broker & `/ui?tab=cluster` | `127.0.0.1:8080` HTTP already shares model weights across apps with `0 B` duplication. | Keep `qwg cluster` CLI-only (`< 40 µs` TB5 RTT gate) if multi-Studio `671B+` hardware demands it. |
