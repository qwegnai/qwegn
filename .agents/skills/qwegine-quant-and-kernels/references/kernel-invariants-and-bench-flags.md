# Low-Level Kernel, Residency & Benchmark Flag Invariants

Reference sheet for `qwegine-quant-and-kernels`. Consult when tuning residency, KDA/GDN rollback, Split-KV callers, `paired_perf.py` flags, or bisecting release metallib regressions.

## 1. Operator Fast-Path & High-UMA (`>= 75%`) Residency

- **MoE NAX Tile Occupancy & Subquadratic Slicing:** Preserve full `4096`-row MoE NAX tile occupancy across CLI and `QWServer`, exempting subquadratic MLA/LSA/HCA paths from quadratic `> 131K` chunk clamps via command-buffer slicing.
- **Disjoint Prefill Scratch Aliasing & `skipOut32`:** Alias disjoint prefill scratch (`DriverConfig.swift`, `DriverInitPhases.swift`) and set `skipOut32` (`hasOut16` bit `128`) whenever FP32 MoE combine output is unread.
- **High-UMA Eviction & `MAP_SHARED` Discipline:** Shrink `prefillChunkSize` before spilling MoE experts to SSD in `DriverResidency`; reserve `(1 << 30)` (not `6 GiB`) headroom for read-only `MAP_SHARED` `QWMTPEmbeddingTable`; auto-evict `PrefillScratch` across both `DenseModule` and `HybridMoEModule` when `wiredEngineBytes >= 75%` of physical RAM; exclude unused `MAP_SHARED` tables (`QWMTPEmbeddingTable` when `mtpDrafts <= 1`) from `MTLResidencySet`.
- **Single-Pass Verify & Hybrid Neural Cap:** Extend single-pass verify GEMVs (`AQ`, `SHVQ`, router, `QWHead.encodeBatched`) across `M = 2..8` (splitting `rem == 9` as `5 + 4`), size `QWVerifyWindow.headGroupSums` for `rows * (hidden / 128)`, and cap `.hybrid` neural draft depth at `neuralCap = 1` on sparse MoE (`geometry.numExperts > 0`) via `QWMTPAdaptiveDepth` + `QWTokenRecycler` / `matchLen >= 6` Context PLD.

## 2. Reduction Order, KDA Rollback, Split-KV & Argmax Scratch

- **Grouped-NAX SRAM LUTs & `-O2` Fast-Math Order:** Wire `DECL_TG` / `PREP_TG` (`HAS_TG = true, tgLut.ptr16()`) into dense NAX (`qwg_gemm_shvq*`) and Grouped-NAX MoE kernels (`qwg_moe_nax_gemm_shvq*`, `qwg_moe_nax_split_shvq*_f32`), scale `groupedNaxMinRows` with `E / K`, align precast dense/shared paths (`T >= 16`), and dispatch `BM = 16 / 32` NAX specializations for `M <= 32`. Preserve exact `master` FP32 `fma` accumulation order (`Scripts/build_metallib.sh` compiles with `-std=metal4.0 -O2`).
- **KDA Rollback Conditioning:** Keep `QWGDNReplayCheckpoint.rollbackTapeIsStable` at per-row AND cumulative `>= 1.0e-3` (`-6.907755`) so 1-row KDA rejections (`gate_lower_bound = -5.0`, `exp(-5.0) = 0.006738`) stay on `encodeRollbackTape` while `>= 2` rejections route to barrier-synchronized `encodeRestore + encodeReplay`.
- **Split-KV Caller Parity (`QWAttnDecode`):** Whenever changing `QWAttnDecode.splits`, sync every caller (`QWHybridLayerKernels`, `QWMTPBatchedTrunk`, `QWMTPDraftEncoder`, `QWEchoDraftEncoder`), preserve the `>= 8` short-context floor (`keys <= 512`) so `MTP` verification matches serial decode (`QWMTPNextNParityTests`), and keep `partials` writes unconditional at `splits == 1` (`QWAttnDecodeGeneralTests`).
- **Latent-Attention MTP Argmax Partials:** When `usesLatentOrCompressedAttention == true`, size fused draft-head argmax scratch for full `vocab` via `QWEngineDriver.draftHeadArgmaxPartialsBytes(vocab:)` instead of collapsing to `4096 B`.

## 3. `paired_perf.py` Flag Contract & 2×2 Release Bisection

- **`--strict` Runs (`Scripts/paired_perf.py`):** Use `--samples >= 5 --warmups 1 --cooldown-seconds 5` (prevents thermal droop across `80–98 GiB` packs), pass `--options-json` as a raw JSON array string containing all required flags (`--lsa-mode`, `--mtp-draft-strategy` [`hybrid|neural|ngram`, never `"mtp"`], `--mtp-drafts`, `--mtp-relaxed-margin`, `--mtp-relaxed-min-prob`, `--repetition-penalty`, `--seed`, `--temperature`, `--top-k`, `--top-p`, `--no-profile`), omit `"--mtp-backend"` when `"--mtp-drafts", "0"`, and verify `--output` does not pre-exist.
- **Non-`--strict` Sweeps (`DFlash 2` / `DSpine` / `HyperStream` / `Inkling2Runtime`):** When `--dflash-window`, non-`standard` `--mtp-backend` (e.g. `dspine`), or multi-100 GB `.qwp` packs are tested, invoke `Scripts/paired_perf.py` without `--strict`, pass all pinned `--options-json` flags (`--samples >= 5 --warmups 1 --no-prefix-cache --no-profile`), and explicitly verify `output_hashes_match`, `token_counts_match`, and `steady_allocations == 0`.
- **CLI Flag Notes:** Read pack geometry from `~/.qwg/models/<pack>/assets/config.json` (`text_config` for multimodal), stripping `*template*` keys (`Law 24`). `qwg run` uses `--max-tokens` (not `--max-new-tokens`) and `--no-thinking`; `--lazy`/`--no-lazy` is `qwg serve`-only (`--load-vision`/`--no-load-vision` works on `qwg run`; use `qwg serve --no-lazy` for server RSS deltas). Seeded stochastic (`--seed >= 0`, `temperature > 0`) runs serial deterministically.
- **2×2 Release vs Local Metallib Matrix:** When bisecting speculative divergence or GitHub Release garbage logits before assuming silicon differences (e.g. M5 Pro vs M5 Max), run `{release qwg, local qwg} × {release kernel.metallib, local kernel.metallib}` via `QW_METALLIB=<path>/kernel.metallib` (`QWHal.swift` reads `QW_METALLIB`, not `QW_METALLIB_PATH`), pair with `--gdn-prefill naive` (skipping NAX) and `xcrun -sdk macosx metal-readobj --headers`, and probe `qwg_gemm_q4g_h16` vs non-NAX `qwg_gemv_q4g_dx_h16_t4`.
